# Handouts for the leaders' session

Everything the facilitator sends or prints for the [leaders' session](../README.md). Each one is
ready to use: change the bracketed parts of the emails, print the rest as it is.

| Handout | Used in | Print | Hand out |
|---|---|---|---|
| [Pre-session email](pre-session-email.md) | One week before | Not printed | Sent by the sponsor to every leader |
| [Three answers](answer-cards.md) | Block 1 | Cards: one set per table. Voting cards: one set per person. Reveal sheet: one per person | Cards at 0:05. Reveal sheet after the vote |
| [Whose fault was it?](trace-exhibit.md) | Block 2 | The trace: one per person. Reveal sheet: one per person | Trace after the first vote. Reveal sheet after the second |
| [Would you have shipped it?](scoreboard-exhibit.md) | Block 3 | Part 1 and Part 2: one each per person | Part 1 at 0:33. Part 2 after the vote |
| [Workflow scorecard](workflow-scorecard.md) | Block 4 | Scorecard: one per person, and one more per table. Example: one per table | On the tables during the break |
| [Approval-gate map](gate-map.md) | Block 5 | One per table, with the example on the back. One drawn large on the wall | At 1:25 |
| [One-page pilot plan](pilot-plan.md) | Block 6 | One per table, with the example on the back. One drawn large on the wall | At 1:43 |
| [Five questions for leaders](../../handouts/questions-for-leaders.md) | Close | One per person | At 1:55 |
| [Exit card](exit-card.md) | Close | One per person | At 1:55. Collected at the door |
| [Follow-up emails](follow-up-emails.md) | The next morning, week one, day 30, day 60 to 90 | Not printed | Leaders, the owner and the sponsor |

Also print the workflows the leaders sent, one per slip of paper, and write the
[data rule](../../docs/FACILITATOR.md#the-data-rule) on the board.

**To print a handout,** open the file on GitHub and print from the browser, or export it to PDF.
Each handout has a line across the page where a new sheet starts.

**Keep the reveal sheets back.** The three exhibits each have a part the room must not see before
it votes. Those parts sit under their own heading. Print them on separate sheets, and keep them
face down at the front.

The pilot plan is the one that matters most. The other handouts exist to get the room to the point
where it can fill that page in and sign it.
